Privacy Policy — Tab Tidy

Last updated: October 25, 2026
Publisher: EazyD Studio
Contact: hello@eazydstudio.com

Overview

Tab Tidy is a Chrome extension that helps you organize tabs, save browsing sessions, optionally park idle tabs, and search open tabs. We respect your privacy and keep your data on your device.

Data we access

When you use Tab Tidy, the extension may access:

  • Open tab titles and URLs (to group, search, save, or restore sessions)
  • Your extension settings (stored locally)
  • Named sessions you create (stored locally)

Tab Tidy does not run content scripts on web pages and does not request host permissions.

Data we collect

We do not collect, transmit, or sell your personal data.
Tab Tidy does not send tab information, sessions, or usage analytics to EazyD Studio or any third party.

Data storage

Sessions and settings are saved with Chrome’s storage API on your computer. You can export or delete sessions from the extension popup or options page.

Optional features

If you enable Park tabs, Chrome will prompt for the optional alarms permission so Tab Tidy can check idle tabs periodically. Idle tab metadata (timestamps) is stored locally to decide when to save and close tabs. This feature is off by default.

Children

Tab Tidy is not directed at children under 13.

Changes

We may update this policy. Continued use after changes means you accept the updated policy.

Contact

Questions or requests: hello@eazydstudio.com

Privacy Policy — Image Toolbar Plus

Last updated: October 24, 2026
Publisher: EazyD Studio
Extension: Image Toolbar Plus

Summary

Image Toolbar Plus does not collect, store, or transmit personal data to EazyD Studio or any third-party analytics service.

Data handling

What we do not do

  • No account registration or login
  • No analytics, advertising, or tracking pixels
  • No sale or sharing of user data
  • No remote code execution — all features run from the packaged extension files

What stays on your device

Your preferences (button toggles, toolbar position, minimum image size, site blacklist, save folder pattern, default search engine) are stored with the Chrome storage API (chrome.storage.sync when sync is enabled, otherwise local).

When you use Save, Chrome’s downloads API saves files to your computer using URLs you choose. We do not receive those files or URLs.

When you use Reverse image search, your browser opens Google Lens, Bing, or TinEye with the image URL you selected. Those sites have their own privacy policies.

Permissions

Permission Why it is needed
storage Remember your settings
downloads Save images you request
contextMenus Add image actions to the right-click menu
activeTab Support keyboard shortcuts in the active tab
tabs Deliver save/copy commands to the correct tab
offscreen Write copied image bytes to the clipboard
Host access (<all_urls>) Fetch image data for save/copy and show the toolbar on pages you visit

The extension injects a content script on http and https pages so it can show the toolbar on images you view. It does not run on pages you have blacklisted in options. Copied images are processed locally; image bytes are not sent to EazyD Studio.

Children

The extension is not directed at children under 13 and does not knowingly collect information from them.

Changes

We may update this policy for clarity or legal compliance. The “Last updated” date will change when we do.

Contact

Questions about privacy: hello@eazydstudio.com
